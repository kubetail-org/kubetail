# docs

Documentation for people working on Kubetail itself. User documentation lives at [kubetail.com](https://www.kubetail.com).

- **[`adr/`](adr/)** — Architecture Decision Records: why the design is the way it is, and what was rejected. Start at [`adr/README.md`](adr/README.md).
- **`specs/`** — plans for work that crosses components and is not finished yet, created when the first one exists. A spec for one component lives in that component's own `docs/specs/`. Delete a spec when its work is done.

The `CLAUDE.md` guides beside the code state what is true now. They link here wherever a reader might ask "why".
