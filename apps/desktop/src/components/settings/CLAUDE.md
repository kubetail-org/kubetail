# src/components/settings — the settings dialog

The settings dialog and the folder-grant form. Also owns `src/lib/`'s `sandbox-*.tsx`, `cluster-scope.ts`, `env-vars.tsx`, `permission-settings.tsx`, `permission-pattern.ts`, `provider-credentials.tsx`, `tool-settings.tsx` and `settings-tab.ts`.

**A hidden tab's pane unmounts**, so its watches run only while it is selected. A pane selects another tab through `useSelectSettingsTab()` (`src/lib/settings-tab.ts`). Every string from a cluster, the user, the sidecar or a command goes through `VisibleText`. A query's hook re-asks after a mutation, and on focus where another window can change it. Placeholders are marked in code (`// Placeholder: awaits …`).

- **Clusters**: nothing draws before the `Bookmark`. Its actions are `ClusterSyncPanel`'s mutations (`src/lib/cluster-mutations.ts`), with no confirm.
- **Connectors**: nothing draws before each watch's first frame; a row's actions follow the connection's phase. A `Restoring` row draws `CHECKING_KEYCHAIN`, no action; OpenRouter's signed-out detail does too while its provider restores. `failureText` is a `Record` over `ConnectorFailure`, so a new failure fails the build. ChatGPT's first connection is confirmed once, in the window that connected (`kubetail:chatgpt-plan-confirmed`; the pending sign-in is `sessionStorage`'s, so it outlasts the pane). Disconnect is confirmed: OpenRouter's and GitHub's credential stays live there, AWS's session until it expires.
- **Providers**: nothing draws before both `useProviderCredentials()` and `useModels()` answer. `Restoring` is `status: 'checking'`, no action. **The webview's one typed secret**: `provider-setup-form.tsx` holds the key, and the hook sends it through `client.mutation(...).toPromise()`, never `useMutation`, whose state would keep it. → [record](../../../docs/security/2026-11-20-saved-provider-keys.md).
- **Tools** (`useToolSettings`): a switch per tool, held on for an `alwaysOn` tool.
- **Monitoring** (`useMonitorTargetEnabledSet`): a switch per target, drawing the watch's `enabled`, never its press. Only a target that is on draws `MonitorTargetStatus`: its off line opens this tab by the label `Monitoring`. A `Denied` permission says so.
- **Memory** shows one scope (*Every cluster* or a cluster, by `ScopePicker` over `useScope`), drawing `components/cluster/`'s memory instructions and list (the cluster guide, *Memory*), keyed on the scope. It is the one way to memory. Every cluster's notes ride on the window's cluster's watch, else the first record's.
- **Environment** (`useEnvVars(clusterID)`) is the user's variables for one scope, picked as Memory's is; the form is keyed on the scope. A refused variable is drawn on its own row with its reason.

## Sandbox

With `available: false`, the tab draws the status card alone, and Permissions says why nothing applies. *Try a command* (`sandbox-console.tsx`, `useSandboxConsole`) folds `sandboxConsoleStateWatch` into a history by command number; closing it stops a running command. *Custom* environment lists every cluster's variables for sandboxed commands (`useEnvVars(null)`) and edits none.

- **New chats** (`useSandboxDefault`, `useSandboxDefaultSwitch`): the status card's switch is every cluster's default; *New chats on a cluster* picks one cluster (`ScopePicker`, `everyCluster={false}`). Starting new chats outside, or a reset that would, confirms in a `Dialog`.
- **`PATH`** (`useSandboxPath`): the card edits one string, `sandboxPathSet`; a taken save or import probes the executables. A draft hiding a character is drawn again through `VisibleText`, since a text field shows none. Add, offered only where `addable`, appends the folder's `target` to the draft, unsaved. A save answered `KUBETAIL_SAVED_UNREAD` took. → [ADR](../../../docs/adr/2026-11-24-the-sandbox-path-is-one-setting-the-user-writes.md).
- **Executables** (`useSandboxExecutables`): the probe mutation answers at once and the watch carries the end. A refused registered executable draws its `refusal` in place of a probe result. A row is keyed by whether it is registered and its name, since a registered name can be a curated one's. A register answered `KUBETAIL_SAVED_UNREAD` took: the form clears and the message stays. After a press, *Probe again* holds until the watch's `probes` count passes the one seen at the press — the answer and the frame race, and a gauge can fold a short probe's start into its end.
- **Folders** (`useSandboxFolders`). **`FolderGrantForm`** (`folder-grant-form.tsx`) is the one form granting a folder, here and in the transcript; it sends the path as typed. A grant's access and Remove depend on no rule: only its own removal in flight holds them. `revoke(id, duration)` names whose grant it is, as `folderGrant` does. → [path grants](../../../docs/security/2026-10-04-path-grants.md).
- **Permissions** (`usePermissionSettings`): a cluster's accounts join onto `useClusters()` by `clusterID` and draw once the cluster arrives. A cloud platform `useSandboxCloudAccess` leaves out is marked *Off*. A rule's scope is built by `src/lib/permission-pattern.ts`, the account a literal; an Allow names a target and an account. **An edit is one `permissionRuleUpdate`, keeping the rule's id and place.** → [the permissions engine](../../../docs/security/2026-10-02-the-permissions-engine.md).
